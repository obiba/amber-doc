Audit
=====

The audit lists the data extractions (case reports and interviews exports) and the files downloads, either by users or by API keys (see :ref:`api_keys`).

For each entry are shown:

* **Date**, when the access happened,
* **Accessed by**, the user's email, the participant's code or the API key's name,
* **Access**, the type of access: case reports export, interviews export or file download,
* **Details**, the request parameters, e.g. the filter criteria of an export.

The list can be filtered by type of access, by API key and by date range.
