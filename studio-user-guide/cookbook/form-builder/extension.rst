How to extend to new type of fields?
====================================

The form engine supports custom controls (see `Custom controls <https://www.obiba.org/quasar-json-form/#/start/custom-controls>`_), but they must be integrated in the Amber applications: they cannot be added from Amber Studio. Please contact the OBiBa developers for contribution or collaboration: info@obiba.org or use the `Amber issue tracker <https://github.com/obiba/amber/issues>`_.

The same applies to the functions that can be called in the rules expressions: custom functions can be registered by the applications (see `Custom functions <https://www.obiba.org/quasar-json-form/#/start/rules>`_).
